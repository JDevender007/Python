# 📖 About

Inventory Management System is an Object Oriented Programming project developed using Python, SQLite, and SQLAlchemy.

The application allows users to manage stock items by adding, searching, updating, deleting, and tracking inventory levels through a command line interface. It demonstrates class based design, database integration, CRUD operations, and modular software architecture.

# ✨ Features

- Add Item
- View Items
- Search Item
- Update Item
- Delete Item
- Stock In
