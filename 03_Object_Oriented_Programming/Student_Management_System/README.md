# 📖 About

Student Management System is an Object Oriented Programming project developed using Python, SQLite, and SQLAlchemy.

The application allows users to store and manage student records through a command line interface. It demonstrates CRUD style record management, database integration, modular programming, and SQLAlchemy ORM usage.

---

# ✨ Features

- Add Student
- View Students
- Search Student
- View Top Scorer
- Count Total Students
- SQLite Database Storage
- SQLAlchemy ORM
- Modular Project Structure
