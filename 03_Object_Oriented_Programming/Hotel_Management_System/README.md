A command line Hotel Management System developed using Python, SQLite, and SQLAlchemy. The application manages hotel rooms, guest bookings, and room availability using an object oriented architecture.

# 📖 About

Hotel Management System is an Object Oriented Programming project built using Python, SQLite, and SQLAlchemy.

The application allows hotel staff to manage rooms, register guests, book rooms, check out guests, and monitor room availability through a command line interface.

- Add Room

# 🚀 Installation

```bash
python -m venv .venv
```

Activate

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python src/main.py
```
