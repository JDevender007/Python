# 📖 About

This repository contains Object Oriented Programming projects developed using Python, SQLite, and SQLAlchemy.

Each project demonstrates software engineering principles including abstraction, encapsulation, inheritance, polymorphism, modular programming, database integration, and CRUD operations. Every application follows a structured architecture with reusable classes, clean code practices, and a layered design to simulate real world management systems.
