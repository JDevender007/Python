# 📖 About

Banking System is an Object Oriented Programming project developed using Python, SQLite, and SQLAlchemy.

The application allows users to create bank accounts, deposit and withdraw money, update account details, view balances, and track transaction history through a command line interface. It demonstrates class based design, database integration, CRUD operations, and modular software architecture.
