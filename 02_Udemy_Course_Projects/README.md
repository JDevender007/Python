# 02. Udemy Course Projects

This folder contains beginner level Python projects developed while completing a Udemy Python course. Each project focuses on strengthening fundamental programming concepts through practical, hands on exercises.

## Projects

| Project | Description |
|---------|-------------|
| Anagrams | Check whether two words or strings are anagrams. |
| Bank DB using SQLite | Simple banking system using SQLite for storing records. |
| Card Payment | Basic card payment validation and transaction simulation. |
| Data Cleaning | Clean and process raw data using Python. |
| Journal Manager | Command line application for managing journal entries. |
| Library Management | Basic library management system for books and users. |
| Palindrome | Check whether a word or phrase is a palindrome. |
| Password Checker | Validate password strength using predefined rules. |
| Patient Entry System | Store and manage patient information. |
| Restaurant Menu | Simple restaurant menu management application. |
| URL Parsing | Parse and extract different components of a URL. |
