# 📖 About

Stack & Queue Simulator is a Python desktop application developed using Tkinter to visualize the behavior of Stack and Queue data structures through smooth, step-by-step animations.

The application enables users to perform operations such as Push, Pop, Peek, Enqueue, Dequeue, Front, and Rear while observing how elements are added and removed in real time. Built-in statistics and complexity analysis provide a deeper understanding of these fundamental data structures.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/Stack_Queue_Simulator.git
```

Navigate to the project directory.

```bash
cd Stack_Queue_Simulator
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install the required packages.

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Application
