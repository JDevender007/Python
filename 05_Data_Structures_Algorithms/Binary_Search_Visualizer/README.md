# 📖 About

Binary Search Visualizer is a Python desktop application built with Tkinter to demonstrate the working principles of Binary Search and Linear Search using smooth, step-by-step animations.

The application allows users to generate sorted arrays, search for custom values, adjust animation speed, modify array size, and observe how each algorithm processes data in real time. Live statistics and complexity analysis make it an effective learning tool for students and developers.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/Binary_Search_Visualizer.git
```

Navigate to the project directory.

```bash
cd Binary_Search_Visualizer
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install the required packages.

```bash
pip install -r requirements.txt
```
