# 📖 About

Sorting Visualizer is a desktop application developed using Python and Tkinter to demonstrate the working principles of popular sorting algorithms through animated visualization.

The application enables users to generate random datasets, choose different sorting algorithms, adjust animation speed, modify array size, and observe each comparison and swap in real time. Live statistics and algorithm complexity information provide a better understanding of algorithm performance and efficiency.

This project is suitable for students, educators, and developers who want to learn sorting algorithms through an interactive graphical interface.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/Sorting_Visualizer.git
```

Navigate to the project directory.

```bash
cd Sorting_Visualizer
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install the required packages.

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Application

Run the project using:

```bash
python -m src.main
```

```bash
python src/main.py
```

# 📊 Algorithm Complexity

| Algorithm      | Best       | Average    | Worst      | Space    |
| -------------- | ---------- | ---------- | ---------- | -------- |
| Bubble Sort    | O(n)       | O(n²)      | O(n²)      | O(1)     |
| Selection Sort | O(n²)      | O(n²)      | O(n²)      | O(1)     |
| Insertion Sort | O(n)       | O(n²)      | O(n²)      | O(1)     |
| Merge Sort     | O(n log n) | O(n log n) | O(n log n) | O(n)     |
| Quick Sort     | O(n log n) | O(n log n) | O(n²)      | O(log n) |
| Heap Sort      | O(n log n) | O(n log n) | O(n log n) | O(1)     |
