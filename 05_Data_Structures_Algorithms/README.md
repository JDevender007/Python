# 📖 About

This repository contains a collection of Python projects focused on Data Structures and Algorithms. Each project is designed to explain core computer science concepts through interactive visualizations, simulations, and graphical interfaces.

The projects cover searching, sorting, graph traversal, pathfinding, and linear data structures. They provide hands-on learning for students, developers, and programming enthusiasts while following modern software engineering practices.

---

# 📂 Projects

| No. | Project                    | Description                                                                     |
| --: | -------------------------- | ------------------------------------------------------------------------------- |
|  01 | Sorting Visualizer         | Visualize popular sorting algorithms with real-time animations.                 |
|  02 | Binary Search Visualizer   | Compare Binary Search and Linear Search through interactive visualization.      |
|  03 | Stack & Queue Simulator    | Simulate Stack and Queue operations with animated data structure visualization. |
|  04 | Pathfinding Visualizer     | Explore shortest path algorithms on interactive grids.                          |
|  05 | Graph Traversal Visualizer | Learn graph traversal using Breadth First Search and Depth First Search.        |
