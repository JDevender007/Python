# 📖 About

File Organizer is a command line application built with Python that scans a folder, identifies file types, and moves them into organized directories such as Images, Documents, Videos, Music, Archives, Python, and Others.

The project demonstrates file handling, directory management, logging, modular programming, and clean project organization.

---

# ✨ Features

- Automatically organize files by extension
- Create folders automatically
- Prevent duplicate filenames
- Generate activity logs
- Simple command line interface
- Modular project structure
- Error handling

# ⚙️ Installation

```bash

cd 04_File_Handling/File_Organizer

python -m venv .venv

.venv\Scripts\activate

```
