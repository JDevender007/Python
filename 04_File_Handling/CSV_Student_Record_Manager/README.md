# 📖 About

CSV Student Record Manager is a Python command line application that stores and manages student information using CSV files. It supports creating, viewing, updating, deleting, searching, sorting, and reporting student records while following a clean modular architecture.

This project strengthens Python fundamentals through practical file handling and data management.

---

# ✨ Features

- Add student records
- View all students
- Search students by roll number
- Update student information
- Delete student records
- Sort students by name
- Sort students by marks
- Calculate average marks
- Generate CSV reports
- Application logging
- Input validation
- Modular project structure

# ⚙️ Installation

```bash
git clone https://github.com/JDevender007/Python.git

cd 04_File_Handling/CSV_Student_Record_Manager

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt
```

---

# ▶️ Run

```bash
cd src

python main.py
```
