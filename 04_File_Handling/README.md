# 📖 About

This repository contains Python projects that demonstrate practical file handling techniques and real-world automation tasks.

The projects cover reading and writing files, organizing directories, detecting duplicate files, synchronizing folders, analyzing log files, and managing structured CSV data. Each project follows a modular architecture with clean code, logging, reporting, and error handling.
