# 📖 About

This repository contains Python projects focused on API development - both consuming external APIs and building REST APIs.

Projects cover weather services, currency conversion, GitHub API integration, news aggregation, and building a complete REST API with FastAPI including database integration, validation, and automatic documentation.

---

# 🎯 Learning Objectives

- Consume REST APIs with Python Requests
- Handle API authentication (API keys, OAuth)
- Parse and validate JSON responses
- Error handling and retry logic
- Rate limiting and caching
- Build REST APIs with FastAPI
- Pydantic models for validation
- SQLite database integration
- Automatic API documentation (Swagger/OpenAPI)
- API testing with pytest
