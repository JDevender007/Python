# 📖 About

Email Automation is a Python desktop application built with Tkinter that simplifies email communication by providing a graphical interface for sending emails through SMTP. The application supports single and multiple recipients, email templates, attachments, and real-time status updates.

The project follows a modular architecture using Object-Oriented Programming principles, making it suitable for learning desktop application development, SMTP communication, and Python software design.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/Email_Automation.git
```

Navigate to the project directory.

```bash
cd Email_Automation
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies.

```bash
pip install -r requirements.txt
```

---

# ▶️ Run

```bash
python -m src.app
```
