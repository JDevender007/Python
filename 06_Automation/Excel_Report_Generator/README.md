# 📖 About

Excel Report Generator is a Python desktop application that simplifies Excel data analysis and report generation. Users can load Excel workbooks, preview datasets, generate statistical summaries, analyze missing values, create charts, and export processed reports through a modern graphical interface.

The project follows a modular Object-Oriented Programming architecture and demonstrates practical usage of Pandas, OpenPyXL, Matplotlib, and Tkinter for business reporting and data analysis.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/Excel_Report_Generator.git
```

Navigate to the project directory.

```bash
cd Excel_Report_Generator
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies.

```bash
pip install -r requirements.txt
```

---

# ▶️ Run

```bash
python -m src.app
```
