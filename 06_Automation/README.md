# 📖 About

This repository contains automation projects developed using Python to simplify common desktop tasks and improve productivity. Each project focuses on solving practical problems through automation while demonstrating clean code architecture, Object-Oriented Programming, modular design, and desktop application development.

These projects cover PDF management, file organization, email automation, folder backup solutions, and Excel report generation, providing hands-on experience with real-world automation workflows.

---

# 📂 Projects

| No. | Project | Description |
|-----|---------|-------------|
| 01 | PDF Merger | Merge multiple PDF files into a single document through a desktop interface. |
| 02 | Bulk File Renamer | Rename multiple files in bulk using customizable naming patterns. |
| 03 | Email Automation | Send emails with attachments, templates, and SMTP integration. |
| 04 | Folder Backup Tool | Create, verify, and schedule automatic folder backups. |
| 05 | Excel Report Generator | Analyze Excel files, generate reports, visualize data, and export results. |
