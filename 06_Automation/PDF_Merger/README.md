# 📖 About

PDF Merger is a desktop application developed with Python and Tkinter for combining multiple PDF documents into a single PDF file. Users can add, remove, reorder, and merge PDF files while viewing page counts and file sizes before generating the final document.

The application follows a clean modular architecture with reusable components, making it suitable as a production-quality portfolio project.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/PDF_Merger.git
```

Navigate to the project directory.

```bash
cd PDF_Merger
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies.

```bash
pip install -r requirements.txt
```

---

# ▶️ Run

```bash
python -m src.app
```

or

```bash
python src/app.py
```
