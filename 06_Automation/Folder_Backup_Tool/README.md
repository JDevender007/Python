# 📖 About

Folder Backup Tool is a Python desktop application built with Tkinter that provides an efficient solution for backing up folders and managing backup operations. The application supports full folder backups, backup verification, scheduled backups, and backup history while providing a clean and user-friendly interface.

The project follows a modular Object-Oriented Programming architecture, making it an excellent project for learning file management, desktop application development, automation, and Python software design.

# 🚀 Installation

Clone the repository.

```bash
git clone https://github.com/JDevender007/Folder_Backup_Tool.git
```

Navigate to the project directory.

```bash
cd Folder_Backup_Tool
```

Create a virtual environment.

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies.

```bash
pip install -r requirements.txt
```

---

# ▶️ Run

```bash
python -m src.app
```
