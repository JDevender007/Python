# 📖 About

Edge Detector implements the classic gradient operators — **Sobel, Prewitt and the Laplacian** — as hand-written 3×3 convolutions in pure NumPy (reflect-101 border handling, no SciPy, no cv2 in the maths), then compares the result against **OpenCV's Canny** detector as an independent cross-check. The demo runs on three **procedurally generated PNGs** bundled in `data/` — a linear gradient ramp with known analytic slopes, a shapes scene (square, disc, diagonal band, ring), and a noisy step edge for hysteresis thresholding.

The report shows per-method edge-pixel counts, the **IoU between each gradient method and Canny**, and a downsampled **ASCII preview** of the edge map. `--file` analyses any local image with a chosen method, thresholds, and optional JSON export.

Everything is deterministic and offline: the bundled PNGs are regenerated by the in-repo generator during the demo and compared byte-for-byte against the shipped files, proving no data was downloaded. **No network, no API keys, no model files.**

# ✨ Features

- `convolve2d()` — from-scratch 2-D convolution with reflect-101 padding
- Sobel / Prewitt `(gx, gy)` pairs, Laplacian second derivative, gradient magnitude
- `canny_edges()` — OpenCV Canny hysteresis as the reference detector
- Analytic verification: a ramp of slope 4 must yield `gx == 32`, `gy == 0`, `laplacian == 0`
- cv2 cross-checks: Sobel/Prewitt/Laplacian match `cv2.Sobel` / `cv2.filter2D` / `cv2.Laplacian` to `1e-6`
- IoU (Jaccard) agreement between every gradient mask and the Canny mask
- ASCII renderer that downsamples any edge map to a 64-column shade preview
- Strict validation: missing/undecodable/tiny images, non-finite kernels, threshold ordering — all validated **before** any pixel work
- Bundled deterministic samples: 3 procedural PNGs rebuilt from the generator at demo time
- 50 passing pytest tests

# ▶️ Run

```bash
# Offline demo: bundled samples, cv2 cross-checks, ASCII preview
python src/main.py --demo

# Detect edges in your own image (from-scratch Sobel)
python src/main.py --file photo.png --method sobel --threshold 40

# Canny comparison with custom hysteresis thresholds
python src/main.py --file photo.png --method canny --low 60 --high 180

# Every method + JSON statistics
python src/main.py --file photo.png --method all --json report.json
```

Input schema (any 8-bit image OpenCV can decode, at least 8×8):

```text
photo.png   # PNG/JPG grayscale or colour (colour is converted to grey)
            # pixels 0..255, both dimensions >= 8
```

**Exit codes:** `0` = success · `2` = usage/schema/threshold error.

# 🧠 How It Works

```text
data/*.png ──► verify byte-for-byte against the procedural generator
                        │
                        ▼  hand-written 3x3 convolution (reflect-101)
      Sobel gx, gy ──► magnitude ──► threshold ──► edge mask ─┐
      Prewitt gx, gy ─► magnitude ──► threshold ──► edge mask ─┤   IoU vs Canny
      Laplacian ──────► |response| ─► threshold ──► edge mask ─┤◄──────────────┐
                                                               │              │
                                  cv2.Canny (low, high) ──► reference mask ────┘
                        │
                        ▼
        edge counts, IoU table, 64-column ASCII edge preview
```

Details worth knowing:

- **Convolution is implemented as correlation with an explicit reflect-101 pad** (`np.pad(..., mode="reflect")`), which is exactly OpenCV's `BORDER_REFLECT_101` — so the from-scratch operators can be compared to cv2 numerically, not just visually.
- **Analytic ground truth**: for a ramp `I(x) = 4x`, the Sobel x-kernel (column weights −4/+4) gives `gx = 4·(I(x+1) − I(x−1)) = 32`, Prewitt gives 24, and any Laplacian of a linear ramp is 0 — the demo asserts all three.
- **cv2's `Laplacian(ksize=1)`** is the unsmoothed 4-neighbour kernel `[[0,1,0],[1,-4,1],[0,1,0]]`; `ksize=3` is a *smoothed* second derivative, so the honest comparison uses `ksize=1`.
- **Gradient masks are thick, Canny masks are thin**, so a perfect IoU is impossible — the demo asserts a realistic lower bound (measured ≈ 0.45) instead of equality.
- **Every flag is validated before the image is touched** — a bad `--low/--high` pair fails in microseconds without decoding anything.

# 📚 Concepts Covered

- 2-D convolution vs correlation and border handling (reflect-101)
- First-derivative operators: Sobel vs Prewitt (smoothing vs uniform weights)
- Second-derivative operators and why the Laplacian vanishes on a plane
- Gradient magnitude and thresholding for edge extraction
- Canny pipeline: Gaussian smoothing → gradients → NMS → hysteresis
- Measuring mask agreement with IoU/Jaccard
- ASCII raster rendering of a boolean mask (no plotting libraries)
- Deterministic procedural data generation and byte-exact verification
- Fast-fail CLI design: validate flags before expensive work
