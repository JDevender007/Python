# 📖 About

This repository contains Python web scraping projects developed as desktop applications with graphical interfaces.

Each project demonstrates practical web scraping techniques including HTTP requests, HTML parsing, data extraction, filtering, export capabilities, and database storage. The projects follow modular architecture with clean code practices, logging, and error handling.

---

# 🎯 Learning Objectives

- Master web scraping with Python
- Work with HTTP requests and responses
- Parse HTML using BeautifulSoup
- Extract structured data from webpages
- Handle pagination and navigation
- Manage rate limiting and politeness
- Export data to CSV, JSON, and databases
- Build desktop GUI applications
- Implement modular project architecture
- Practice error handling and logging
